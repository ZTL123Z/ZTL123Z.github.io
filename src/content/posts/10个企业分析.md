  - 在这里“爆肝”1-2年，攒出一手极其漂亮、且经过市场检验的**商业作品集**，后续直接跳槽去正规研发公司做自研，是一条非常经典的行业晋升路线。

## 8.黄冈三新技工学校有限公司（计算机教师兼教务助理）

### 1. 是否外包？（否）

**不是外包。属于私立中职/技工学校的直招教职。**

- **定性：** 这是一所民办性质的技工学校。你入职后是直接跟学校签订劳动合同，属于学校的正式教职工。
- **注意点：** 虽非外包，但因为带了“有限公司”四个字，说明它是**纯民营资本运作的商业化学校**，没有国家事业编制，属于合同制员工。

### 2. 天眼查与学校背景起底

- **办学层次：** 属于**中等职业教育（中职/技校级别）**，学生群体主要是初中毕业没考上高中的孩子，或者走单招、职教高考路线的学生。
- **岗位特殊性：** 招聘名称是“计算机教师 兼 教务助理”**。请特别注意**“兼”字，这说明学校在极力精简人力成本。你进去之后一个人要干两份活：
  1. **计算机教师：** 负责给技校学生上计算机基础课（如 Office三件套、计算机组装维护、或者基础的电商/网页制作）。
  2. **教务助理：** 负责学校教务处的行政杂事。比如排课表、管理学生学籍档案、整理教学评估资料、配合教育局和人社局的各种检查。

### 3. BOSS直聘招聘真相

在招聘平台上，这类民办中职/技校的招聘通常呈现以下特征：

- **门槛相对亲民：** 相比于公办中职动辄要求研究生或者公招考试，民办技校对计算机教师的要求一般放宽到**优秀本科生**，甚至只要你技术过关、口才好、能管得住学生即可。
- **薪资构成与真实水平：**
  - 在BOSS直聘上，这类岗位的综合月薪通常在 **3.5K - 6K** 左右（在黄冈当地属于正常水平）。
  - **薪资结构：** 基本工资 + 课时费 + 教务行政绩效 + 班主任津贴（如果被安排当班主任）。
- **工作强度：** 因为兼任了教务助理，你的基本作息会变成“行政坐班制”。没课的时候你要在办公室处理教务表格，有课的时候要去教室上课，属于典型的“高连轴转”状态。

### 4. 小红书/全网中职教师真实反馈

- **最头疼的事：学生管理（“兼职当保姆”）**
  - 技校的孩子正处于青春期，且普遍厌学、纪律性较差。在小红书上，民办技校老师吐槽最多的不是教学累，而是**管纪律累**。上课要防着学生睡觉玩手机，一旦学生在学校抽烟、打架或者出安全事故，老师会面临巨大的管理压力。
- **民办学校的死穴：暑假招生 KPI**
  - 和前面的民办大专类似，民办技校极其依赖每年夏天的生源来维持运转。到了 6-8 月，所有年轻老师通常都会被分派**招生指标**。你需要顶着太阳去各个初中摆摊、去乡下挨家挨户家访、或者在电话里疯狂推销学校拉学生报名。**如果招不满人，可能会直接扣除绩效，甚至影响续签合同。**
- **唯一亮点：稳定的假期**
  - 虽然平时教务杂事多、管学生心累，但学校毕竟是学校，**寒暑假是切实存在的**。虽然民办学校在寒暑假可能只发基本工资（或者打折发放），但对于想调理身体、或者想利用假期复习考公、考公办编制的人来说，这依然是个极好的时间窗口。

## 9.北京思明启创科技有限公司（班主任）

### 1. 是否外包？(否)

**不是外包。属于行业头部互联网教育大厂的“直招”岗位。**

- **定性：** 这是少儿编程领域的绝对独角兽企业（得到了高瓴资本、KKR等大机构投资）。你入职后是直接跟核桃编程签订正规劳动合同，不是劳务派遣，也不是第三方代招。
- **实质：** 虽然不是外包，但需要注意，它招聘的“班主任”和“课程顾问”属于**劳动密集型的互联网销售/服务大后方岗位**。

### 2. 天眼查数据透视

- **企业规模：** 成立于2017年，C轮融资高达2亿美元。目前总部在北京海淀，但在**武汉（中电智谷等）、西安、郑州、成都、重庆**等大城市设立了庞大的运营和交付基地，员工总数在 5000~10000 人级别。
- **企业稳定性：** 在当年的“双减”政策中，由于他们主打的是“少儿编程、科学素质教育”，属于非学科类，因此完美避开了毁灭性打击，甚至承接了许多从K12转型过来的流量，目前经营状况在教培行业里算非常稳定的。

### 3. BOSS直聘招聘真相

在BOSS直聘以及各大高校就业网上，该公司的招聘话术和薪资构成非常有针对性：

- **岗位黑话拆解：**
  - **班主任（或称 课程导师 / 用户运营 / 编程老师）：** 不要被“老师”两个字迷惑。这个岗位基本不要求你懂很高深的 C++ 或 Python。核桃主打的是“AI人机双师模式”，即孩子跟着AI动画系统学，你的主要工作是**给孩子答疑（图形化编程错在哪）+ 维护家长群 + 核心 KPI：续费与转化**。
  - **课程顾问（或称 销售管培生 / 新客顾问）：** 纯粹的**前端销售（电销/网销）**。公司给你体验课的家长名单，你需要疯狂打电话或加微信，把他们转化成几千块的系统长线班。
- **薪资套路：** 招聘挂出的薪资非常诱人，往往是 **“10.5K - 15K”**，甚至年薪 10w-12w。
  - **真实构成：** 基本底薪在 4000-5000 元左右，剩下的全靠**续班率、完课率、转介绍或销售提成**。
  - **工作时间：** 属于典型的“错峰作息”，通常是 **13:00 - 21:00**（因为要等孩子放学、家长下班），通常是**周二周三双休**，周末两天是工作高峰期，必须全天在线。

### 4. 小红书/全网员工真实反馈

在小红书输入“核桃编程 离职”或“核桃班主任”，你会看到极多前员工的“血泪史”与避雷心得，核心痛点高度集中：

- **披着教育皮的“销售修罗场”：**
  - 小红书上吐槽最狠的就是“续费周（俗称大周）”。在续费节点，每个班主任都有死指标，必须疯狂给家长打电话、发微信长文，甚至求着家长续费。如果完不成指标，会被主管单独约谈、留下来复盘，心理压力极大。
- **严重的隐形加班和“随时待命”：**
  - 虽然规定晚上9点下班，但九点后往往还要开“复盘会、夕会”。更难受的是，家长随时会在晚上10点、11点在微信上质问你“孩子这道题怎么报错了”，你为了满意度必须秒回。手机微信永远在响，很难把工作和生活分开。
- **亮点与优势（并非全是缺点）：**
  - **钱不画饼：** 如果你销售能力强，情商高，擅长跟家长搞好关系，在业务高峰期拿 1w+ 甚至 2w 的月薪是真实存在的，提成发放比较准时。
  - **大厂规范：** 五险一金齐全，办公环境多在甲级写字楼，里面年轻人非常多（基本都是刚毕业一两年的大学生），团队氛围比较有活力，没有传统企业的勾心斗角，只有纯粹的业绩内卷。

## 10.孝感创兴中等职业学校有限责任公司（老师等等）

### 1. 是否外包？（否）

**不是外包。属于民办中等职业学校的“直招”教职。**

- **定性：** 这是一所全日制中等职业学校（中职/中专）。你入职后是直接跟学校签订正式的劳动合同，属于学校的正式教师。
- **注意点：** 它的名称后缀带有“有限责任公司”，说明它是由**民营资本投资、商业化运作的民办学校**。这里**完全没有国家事业编制**，属于合同制员工。

### 2. 天眼查数据透视（起底学校办学模式）

- **学校定位：** 属于面向初中毕业生（未能考上普通高中的学生）的中等职业教育机构。学校的生存和盈利核心在于两点：**招生规模**和**学生就业率/职教高考升学率**。
- **岗位专业化：** 它这次招聘的岗位非常多（会计、形体、汽修、计算机、数学、英语），涵盖了公共基础课、艺术素质课和专业技能课。这说明学校目前正在**扩建新专业**或者面临**开学前的大规模人员流动换血**。

### 3. BOSS直聘与岗位真相

在招聘平台上，这类民办中职的教师岗位通常具备以下几个典型特征：

- **对技术实操与考证要求高（汽修/计算机/会计）：**
  - 以**汽修教师、计算机教师、会计教师**为例，学校不仅看重你的学历，更看重你能不能带学生进行**实操演练**（比如拆装发动机、组装电脑、做账报税）。如果你拥有相关的行业职业资格证书（如汽车维修工证、初级/中级会计师证、1+X证书考评员等），面试通过率会极高。
- **形体（舞蹈）教师的定位：**
  - 这通常是为学校的“幼儿保育”（原幼师专业）或“高铁乘务/航空服务”等专业开设的配套课程，主要培养学生的职业仪态和才艺。
- **文化课教师（数学/英语）：**
  - 主要负责“职教高考班（对口高职高考）”或者普通中专班的文化课教学。教学内容相对简单（基本是初中到高中衔接的难度），但需要你有较好的课堂纪律掌控能力。
- **薪资待遇：**
  - 在孝感本地，民办中职教师的综合月薪一般在 **3.5K - 5.5K** 左右，通常由“基本底薪 + 课时费 + 班主任津贴 + 绩效奖金”构成。包吃住（提供教师宿舍和食堂）是这类学校的标配福利。

### 4. 小红书/行业员工真实反馈

在中职/技校当老师，全网（特别是小红书上）的年轻同行们反馈的痛点和甜点都非常雷同：

- **核心痛点 1：管纪律和日常管理（“佛系教学，硬核当保姆”）**
  - 中职学生普遍处于叛逆期，学习自主性较差，课堂纪律是极大的挑战。小红书上很多年轻老师吐槽：“上课主要精力不是在讲课，而是在收手机、叫醒睡觉的学生、调解学生矛盾。”
  - 如果你被安排兼任**班主任**，工作量会暴增。从早上查早操、白天盯上课、晚上查寝，到处理学生生病、请假等杂事，心理压力会比较大。
- **核心痛点 2：无法避开的夏天“招生KPI”**
  - 作为“有限责任公司”运作的民办学校，生源就是生命线。每年 6-8 月的招生季，学校通常会给每个老师分派指标。老师需要去各个初中驻点、打电话、或者去乡下家访劝说家长报读。**招生任务能否完成，往往直接挂钩你的绩效和聘用合同。**
- **甜点与优势：寒暑假和稳定感**
  - 比起天天在外面风吹日晒跑销售，或者在互联网外包公司天天加班熬夜秃头，学校的环境相对单纯。
  - **切实享有寒暑假**。即使民办学校在寒暑假可能只发基础保底工资，但能有固定的时间调理身体、陪伴家人，或者利用这段时间**复习备考公办学校的事业编制**，是非常好的缓冲期。
